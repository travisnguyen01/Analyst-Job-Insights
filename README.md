# Data Analyst Job Market Analysis (Seattle Area)

Analyzed 27 data analyst job postings to identify in-demand skills and salary trends using Python, Excel, and Tableau.

## Overview
This project analyzes 27 data analyst job postings to identify the most in-demand skills and salary trends across role levels.

## Process
- Collected 27 data analyst job postings from LinkedIn and Indeed
- Cleaned and standardized data using Python (handled missing values and normalized fields)
- Extracted key skills (Excel, SQL, Python, Tableau, Power BI) from job descriptions using keyword matching
- Aggregated and analyzed data in Excel
- Built interactive visualizations in Tableau to communicate insights

## Tools Used
- Python (data cleaning and skill extraction from job descriptions)
- Excel (data aggregation)
- Tableau (data visualization)

## Key Insights
- Excel (67%) and SQL (63%) are the most in-demand skills across job postings.
- Tableau and Power BI are each listed in 30% of job postings, while Python is less common at 19%.
- Mid-level roles show significantly higher salary ranges compared to entry-level roles, with the upper range being ~$40k higher on average.

## Takeaway
Thes findings suggest for aspiring data analysts that prioritizing SQL and Excel provide a strong foundation for entry-level roles, while broadening skills supports long-term growth.

## Limitations
- Small sample size (27 postings)
- Skill extraction based on keyword matching, which may miss variations
- Results reflect the Seattle area and may not generalize to other markets
- Several job postings lacked detailed descriptions or complete salary information, limiting the depth of analysis
